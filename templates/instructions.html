SESSION ONE / الجلسة الأولى

Booking totals / حساب الحجوزات

All bookings and customers are fictional. Calculate the booking total using these rules:

  1. Multiply nights by the nightly rate.
  2. Add a service fee of 50 EGP.
  3. For four or more nights, subtract a discount of 100 EGP.

اضرب عدد الليالي في سعر الليلة، ثم أضف ٥٠ جنيهًا رسوم خدمة. إذا كانت الإقامة أربع ليالٍ أو أكثر، اطرح خصمًا قدره ١٠٠ جنيه.

Example: 4 nights × 200 + 50 − 100 = 750 EGP.
مثال: ٤ ليالٍ × ٢٠٠ + ٥٠ − ١٠٠ = ٧٥٠ جنيهًا.

SESSION TWO / الجلسة الثانية

A new booking workflow / طريقة عمل جديدة

The system now supplies the booking total. Your task is to choose the action needed for the booking, using two rules:

  1. A prepaid booking needs payment evidence. If it is missing, request it.
  2. If guests exceed the room capacity, resolve the capacity issue.

If both issues occur, resolve both. If neither occurs, confirm the booking. Do not calculate the total; it is already supplied.

النظام يحسب المبلغ تلقائيًا. اختر الإجراء المطلوب: الحجز المدفوع مقدمًا يحتاج إثبات دفع؛ إذا غاب فاطلبه. وإذا تجاوز عدد النزلاء سعة الغرفة، عالج مشكلة السعة. إذا وجدت المشكلتان فاختر معالجة الاثنين. وإذا لم توجد مشكلة، أكّد الحجز. لا تحتاج إلى حساب المبلغ.
